To create a new virtual environment:
python -m venv ~/[insert path here]/[virtual environment name]

To activate an environment:
source ~/[insert path here]/[virtual environment name]/bin/activate

You will need to install Node.js and the npm CLI. More instructions on how to do so at this link:
docs.npmjs.com/downloading-and-installing-node-js-and-npm

To install requirements (assuming virtual environment has been activated and Node.js + npm CLI have been installed):
pip install -r requirements.txt
npm install leaflet react-leaflet
npm install react-leaflet-cluster
npm install react-dom

To detect I2C devices on the Jetson:
i2cdetect -y -r [bus_number]

40 PIN header on Jetson:
sudo i2cdetect -y -r 7
Wires are connected to GPIO pins 3 and 5

System monitoring tool to check resources on Jetson:
jtop

DO NOT USE SUDO UPGRADE

To activate max GPU power
sudo jetson_clocks

Setting up GPS:

Enable serial port
Find what serial port points to:
ls -l /dev/serial0

Jetson config command:
sudo /opt/nvidia/jetson-io/jetson-io.py

Jetson serial port for uart1: ttyTHS1
If starting completely new, will need to adjust permissions

Testing model and 3 cams:
python ./src/Dashboard/src/backend/find_distance.py -r #Allows you to record
(alt: -r, --record,  -R)

python ./src/Dashboard/src/backend/find_distance.py -r -t #Allows you to see what is being recorded at the same time
(alt: -r -T, --test)
While running in test mode the 'I' key starts the ROI editor to manually select ROI mask dimensions

python ./src/Dashboard/src/backend/find_distance.py -r -a #Allows you to record the annotated version
(alt: -a, -A, --annotate)
Running it without args auto runs the server for streaming

How to run application:
Backend:
--- This needs to be set up before frontend! ---
Set up linux backend terminal
While in peterparkers folder run commands ->
source ~/parker-env/bin/activate
python ./src/imu-gps/SensorApp.py
Click local server > Firefox
(Might need to run/try twice if there is uni-code error)

Frontend:
Set up bash or linux frontend terminal
while in peterparkers folder run commands ->
cd src/Dashboard
npm run dev
click local server -> Firefox
